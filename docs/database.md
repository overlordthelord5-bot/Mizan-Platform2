# معجم وهيكلية قاعدة البيانات لمنصة مِيزان | Database Architecture

## 1. مخطط قاعدة البيانات (ERD & Relational Models)
تحتوي قاعدة بيانات منصة **مِيزان** على أكثر من 40 كيانًا وجدولًا منظمًا بأعلى معايير الـ Normalization مع الالتزام بالدقة المالية (Decimal للأموال، وتوقيت UTC لكافة السجلات).

### أ. المستخدمون والملفات الشخصية (Users & Profiles)
- `User`: جدول الحسابات الأساسي مع تشفير كلمات المرور بحماية bcrypt/argon2.
- `CustomerProfile`: بيانات العميل والشركة والرقم الضريبي إن وجد.
- `AccountantProfile`: الملف المهني للمحاسب، رقم قيد نقابة التجاريين، سجل المحاسبين والمراجعين، حالة التوثيق، سنوات الخبرة، والتقييمات.
- `AccountantDocument`: المستندات الرسمية (بطاقة الرقم القومي، كارنيه النقابة، شهادة القيد بالسجل، البطاقة الضريبية).
- `Skill` و `AccountantSkill`: المهارات المحاسبية المعتمدة ومستويات الخبرة.

### ب. التصنيفات والخدمات (Categories & Services)
- `Category`: فئات الخدمات (الضرائب العامة، ضريبة القيمة المضافة، الفاتورة الإلكترونية، تأسيس الشركات، المحاسبة ومسك الدفاتر...).
- `Service`: الخدمات المحددة مع السعر والمدة والمستندات المطلوبة.
- `AccountantService`: تخصيص الأسعار والمدد لكل محاسب.

### ج. الحجوزات والماليات (Bookings & Financials)
- `Booking`: تفاصيل الموعد، العميل، المحاسب، القيمة الإجمالية، عمولة المنصة، وحالة الحجز.
- `Payment`: عمليات السداد وبوابة الدفع ورمز المعاملة المرجعي.
- `Refund`: طلبات وعمليات الاسترداد المالي مع سبب الإلغاء.
- `Wallet` و `WalletTransaction`: محافظ المحاسبين، الأرباح، والعمولات.
- `WithdrawalRequest`: طلبات سحب الأموال عبر إنستاباي (InstaPay) أو التحويل البنكي أو المحافظ الإلكترونية.

### د. التواصل والتوثيق والرقابة (Communications & Audit)
- `Conversation` و `Message`: الرسائل والمستندات المتبادلة داخل غرفة الاستشارة.
- `Review`: تقييمات العملاء المعتمدة بعد إتمام الحجز الفعلي فقط.
- `Dispute`: سجل النزاعات وقرارات الإدارة.
- `AuditLog`: سجل التدقيق المالي والإداري لكافة التغييرات الحساسة.
- `PlatformSetting`: المتغيرات الديناميكية مثل نسبة عمولة المنصة (الافتراضية: 15%).
