# مِيزان | MEEZAN
### المنصة المعتمدة للاستشارات المحاسبية والضريبية والمالية في مصر

---

## 1. نبذة عن المنصة (Overview)
**مِيزان (MEEZAN)** هي منصة إلكترونية احترافية (B2C & Freelancers & SMEs Marketplace) متخصصة في ربط العملاء والشركات الناشئة في جمهورية مصر العربية بنخبة من المحاسبين القانونيين والمستشارين الماليين والضريبيين المعتمدين والمقيدين رسمياً بنقابة التجاريين وسجل المحاسبين والمراجعين بوزارة المالية.

---

## 2. المميزات الرئيسية (Core Features)

### أ. دليل وبحث متقدم للمحاسبين المعتمدين
- فلترة دقيقة حسب المحافظة المصرية (القاهرة، الجيزة، الإسكندرية، الدقهلية، الشرقية...).
- فلترة حسب التخصص (ضرائب عامة، ضريبة القيمة المضافة، منظومة الفاتورة الإلكترونية والإيصال الإلكتروني، تأسيس الشركات GAFI، مسك الدفاتر والقوائم المالية EAS).
- تصفية حسب السعر (EGP)، والتقييمات، وسنوات الخبرة.
- شارات التوثيق الرسمي بعد فحص المستندات ورقم القيد.

### ب. محرك الحجز والدفع والعمولة العادلة
- نظام حجز بـ 5 خطوات متكاملة يمنع تعارض المواعيد.
- شفافية كاملة: عمولة المنصة 15% الافتراضية ومستحق المحاسب 85% واضحة دون أي رسوم خفية.
- لوحة تحكم إدارية تتيح تعديل نسبة العمولة ديناميكياً.
- بوابات الدفع المصرية المعتمدة (ميزة الوطنية، فوري، إنستاباي، فودافون كاش، وبطاقات فيزا وماستركارد).

### ج. غرفة الاستشارة الافتراضية (Consultation Room)
- مؤقت تنازلي دقيق للجلسة (45 دقيقة).
- محاكاة اتصال فيديو وصوت WebRTC مع إمكانية مشاركة الشاشة لمراجعة الفواتير.
- محادثة مباشرة وتبادل المستندات والملفات (PDF، إكسيل، فواتير ضريبية).
- إنهاء الاستشارة ونظام تقييم فوري 5 نجوم للمحاسب.

### د. حاسبة ضريبة الدخل المصرية التقديرية
- مبنية وفقاً لأحدث تعديلات قانون الضريبة على الدخل رقم 91 لسنة 2005.
- تطبيق الشريحة الأولى المعفاة (40,000 ج.م سنوياً) والشرائح التصاعدية حتى 25%.

### هـ. مُستشار مِيزان الذكي (AI Financial Advisor)
- مدعوم بنماذج Google Gemini للرد الفوري على الاستفسارات وتوضيح إجراءات الفاتورة الإلكترونية وتأسيس الشركات.

---

## 3. البنية التقنية (Tech Stack)
- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons, Three.js (مجسم الميزان الذهبي ثلاثي الأبعاد), Canvas Confetti.
- **Backend:** Node.js, Express, TypeScript, REST API, Vite middlewares.
- **Database:** PostgreSQL Schema (Prisma ORM) يضم أكثر من 40 جدولاً وفهارس للبحث وتدقيق العمليات المالية.
- **Unit Testing:** Node.js Built-in Test Runner (`node:test`, `node:assert/strict`).

## 4. تعليمات التشغيل محلياً (Run Locally)

### المتطلبات الأساسية
- Node.js (الإصدار 20 أو أحدث)
- npm

### خطوات التشغيل
1. تثبيت الحزم:
```bash
npm install
```

2. إعداد متغيرات البيئة:
```bash
cp .env.example .env.local
# قم بإدخال GEMINI_API_KEY للاستفادة من الذكاء الاصطناعي
```

3. تشغيل الخادم والتطبيق المدمج:
```bash
npm run dev
```

التطبيق سيعمل مباشرة على: `http://localhost:3000`
